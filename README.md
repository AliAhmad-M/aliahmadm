# Ali Ahmad | Portfolio

Personal portfolio website with my projects, education, skills and a blog on graphics, game engines and reinforcement learning.

Live site: https://aliahmadm.vercel.app/

## Stack

- Next.js 16 (App Router) and React 19
- TypeScript
- Tailwind CSS 4, plus plain CSS files next to the components they style
- `react-markdown` with `remark-gfm` to render blog posts
  
## Deployment

The site is deployed on Vercel at: https://aliahmadm.vercel.app/
